## Add or update files later

Open the relevant session folder on GitHub, choose **Add file > Upload files**, upload your Java files, and commit the changes. Session links stay the same when files are added.

For a local checkout, copy your files into the appropriate session folder, then run:

```sh
git add .
git commit -m "Update session assignments"
git push origin main
```
